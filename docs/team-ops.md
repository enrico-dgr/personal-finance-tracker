# Team Ops

## Regole operative correnti
- Ogni incremento deve includere almeno una validazione eseguibile: test, build o smoke test.
- Ogni modifica che tocca comportamento utente aggiorna anche la documentazione in `docs`.
- Le scelte architetturali vengono tracciate in `docs/decisions.md`.

## Comandi base
- `npm install`
- `npm run db:push`
- `npm run db:seed`
- `npm run dev`
- `npm run build`
- `npm run test:api`
