# Visione

## Obiettivo
Creare una web app personale che trasformi gli export CSV della banca in informazioni leggibili: merchant puliti, categorie affidabili e una vista semplice di dove vanno i soldi.

## Problema che risolve
Le descrizioni bancarie sono rumorose e poco leggibili. Questo rende difficile capire rapidamente quanto si spende, dove si spende e quali movimenti meritano attenzione.

## Principi prodotto
- Determinismo prima di AI: regole e keyword prima di qualsiasi classificazione avanzata.
- Apprendimento dalle correzioni: ogni modifica manuale deve poter migliorare gli import futuri.
- Focalizzazione Italia-first: il sistema parte da formati CSV e descrizioni tipiche di banche italiane.
- Semplicità operativa: upload file, revisione veloce, dashboard chiara.
